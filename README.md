# Matematica facile con Mate e Matica – L'insieme N

Modulo didattico gratuito e navigabile dedicato all'insieme dei numeri naturali.

## Pubblicazione con GitHub Pages

1. Caricare nella radice del repository `index.html`, `README.md` e i tre file PNG: devono trovarsi tutti allo stesso livello.
2. Aprire **Settings → Pages**.
3. In **Build and deployment**, scegliere **Deploy from a branch**.
4. Selezionare il branch `main` e la cartella `/ (root)`, quindi salvare.

Le domande, le risposte e i collegamenti sono raccolti nel blocco `MODULO` verso la fine di `index.html`.
